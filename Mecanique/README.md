La partie mécanique se divise en 3 principales étapes : 
- La plaque de maintient (Switch Plate) qui permettra d'aligner parfaitement les switchs lors de la soudure.
- Les touches de clavier (KeyCaps) pour appuyer sur les switchs
- Le boitier du clavier.
